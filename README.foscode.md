## 📋 项目简介

FosCode（运维智能体）是基于 [OpenCode](https://opencode.ai) 框架二次开发的 AI 助手，专为**非程序员用户**设计，聚焦于 **Linux 系统运维**和**日常办公查询**场景。

### 核心设计理念

```
┌─────────────────────────────────────────────────────────────┐
│                    传统 AI 编程助手                          │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐ │
│  │ 写代码  │ -> │ 改 Bug  │ -> │ 调试   │ -> │ 提交   │ │
│  └─────────┘    └─────────┘    └─────────┘    └─────────┘ │
│                                                             │
│  ❌ 不适合：运维人员、运营人员、普通用户                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    FosCode 运维智能体                        │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐ │
│  │ 系统查询 │ -> │ 性能调优 │ -> │ 故障排查 │ -> │ 许可证  │ │
│  └─────────┘    └─────────┘    └─────────┘    └─────────┘ │
│                                                             │
│  ✅ 适用：运维工程师、SRE、技术支持、业务运营                  │
└─────────────────────────────────────────────────────────────┘
```

## 📦 核心模块

### 1. SysOps Agent (运维智能体)

专门的 Linux 系统运维 Agent，具备以下能力：

- **系统诊断**：CPU、内存、磁盘、网络状态分析
- **性能调优**：系统参数优化、资源利用率提升
- **安全加固**：防火墙规则、系统安全配置
- **故障排查**：日志分析、问题定位、根因分析
- **服务管理**：systemd 进程管理、服务启停

### 2. License 模块 (许可证机制)

智能识别用户请求类型，拦截需要编程能力的代码问题：

```
┌─────────────────────────────────────────────────────────────┐
│                    请求分类流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   用户: "我的 Java 代码有 NullPointerException"             │
│                           │                                  │
│                           ▼                                  │
│   ┌─────────────────────────────────────────────┐           │
│   │  License.classify()                         │           │
│   │  关键词分析: [source, compile, bug, error] │           │
│   │  → 判定为: code (代码类)                   │           │
│   └─────────────────────────────────────────────┘           │
│                           │                                  │
│                           ▼                                  │
│   ┌─────────────────────────────────────────────┐           │
│   │  输出拦截信息:                               │           │
│   │  [LICENSE_REQUIRED]                         │           │
│   │  License code: FOS-CODE-CODE-8F3A2         │           │
│   │  → 请激活代码许可证后继续                   │           │
│   └─────────────────────────────────────────────┘           │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 3. Skill 扩展机制

支持加载外部技能模块，兼容 Claude Code 技能格式：

```
.claude/
└── skills/
    ├── SKILL.md          # 技能定义文件
    └── ...
.agents/
└── skills/
    └── ...
.opencode/
└── skill/
    └── ...
```

## 🛠️ 安装与配置

### 环境要求

- **运行时**: Bun 1.3+ 或 Node.js 18+
- **系统**: Linux (推荐) / macOS / Windows (WSL2)

### 快速开始

```bash
# 克隆项目
git clone https://github.com/chenwei-linux/opencode.git
cd opencode

# 安装依赖
bun install

# 进入 opencode 包
cd packages/opencode

# 启动交互式终端
bun run index.ts
```

### 配置说明

在项目根目录或用户目录创建 `opencode.json`：

```json
{
  "model": "claude-sonnet-4-20250514",
  "permission": {
    "bash": "allow",
    "read": "allow",
    "edit": "deny"
  }
}
```

## 📖 使用示例

### 示例 1: 系统状态查询

```
用户: 检查服务器负载
SysOps:
✓ 已连接到服务器
✓ 执行诊断命令: uptime
✓ 分析结果:
  - 当前负载: 0.52, 0.48, 0.51
  - CPU 使用率: 23%
  - 内存使用率: 67%
  - 磁盘使用率: 45%
结论: 系统负载正常
```

### 示例 2: 故障排查

```
用户: 网站访问很慢
SysOps:
✓ 开始诊断流程
✓ 检查网络连通性: ping -c 4 example.com
✓ 检查 DNS 解析: dig example.com
✓ 检查 Web 服务: curl -I https://example.com
✓ 检查系统资源: top -bn1
✓ 检查连接数: netstat -an | wc -l
结论: 发现问题 - TIME_WAIT 连接数过高 (5000+)
建议: 调整内核参数 net.ipv4.tcp_tw_reuse = 1
```
